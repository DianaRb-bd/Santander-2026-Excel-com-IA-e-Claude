# 🤖 Santander — Excel com IA e Claude

## 🎯 Sobre o Projeto

O projeto tem como objetivo explorar os recursos do Microsoft Excel em conjunto com a Inteligência Artificial, utilizando o Claude como ferramenta de apoio para a organização, análise e interpretação de dados.

## 🛠️ Ferramentas e Tecnologias

- 📊 Microsoft Excel
- 🤖 Inteligência Artificial (IA)
- 🧠 Claude

## 📚 Aprendizados

- Organização e análise de dados utilizando o Excel.
- Exploração de recursos de Inteligência Artificial para apoiar tarefas com planilhas.
- Utilização da IA como apoio à produtividade e à resolução de problemas.
- Desenvolvimento do pensamento analítico e da capacidade de interpretar informações.

## 💡 Objetivo

Ampliar meus conhecimentos em Excel e Inteligência Artificial, explorando como essas ferramentas podem trabalhar em conjunto para facilitar tarefas, apoiar análises e transformar dados em informações úteis para a tomada de decisões.
